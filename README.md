# Mock Server

A lightweight **mock REST API** built with [json-server](https://github.com/typicode/json-server), designed for rapid prototyping and testing frontend applications without a full backend setup.

---

## 🚀 Key Features

- Fully functional mock REST API ready for immediate use.
- Supports all **CRUD operations**: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
- Data persisted in a single `db.json` file for simplicity.
- Easily customizable endpoints and extendable structure.
- Ideal for frontend development, API testing, and demo projects.

---

## 📦 Installation & Usage

Follow these steps to get started:

```bash
# Clone the repository
git clone https://github.com/44fahadhasan/mock-server.git

# Navigate to the project folder
cd mock-server

# Install dependencies
npm install

# Start the mock server
npm start
```
